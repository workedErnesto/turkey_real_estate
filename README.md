# Прогноз цен на недвижимость в Турции

Учебная работа по машинному обучению. По характеристикам квартиры или дома (площадь, комнаты, этаж, возраст здания, отопление, город) модель предсказывает цену в турецких лирах. Есть ноутбуки с анализом и обучением и небольшое приложение: API на FastAPI и интерфейс на Streamlit.

## Запуск

1. Установить зависимости:

   ```bash
   pip install -r requirements.txt
   ```

2. Запустить API из папки `app`:

   ```bash
   cd app
   uvicorn main:app --reload
   ```

3. Во втором терминале запустить интерфейс:

   ```bash
   cd app
   streamlit run app.py
   ```

Исходный датасет лежит в `data/real_estate_data.csv`. Ноутбук `real_estate_analysis.ipynb` делает из него `data/real_estate_processed.csv`, этот файл нужен для вкладки с дашбордом.

## Структура

| Путь | Что там |
|---|---|
| `notebooks/real_estate_analysis.ipynb` | EDA, предобработка, сравнение трёх моделей, сохранение лучшей |
| `notebooks/model_testing.ipynb` | то же самое плюс отдельные модели для продажи и аренды и проверка на 20 новых объявлениях |
| `app/main.py` | API на FastAPI, эндпоинты `/predict` и `/health` |
| `app/app.py` | интерфейс на Streamlit: форма оценки, дашборд, справка |
| `models/` | обученная модель CatBoost, scaler и список признаков |
| `data/` | исходный и обработанный датасеты, 20 тестовых объявлений и предсказания по ним |

## Как делали

1. EDA: посмотрели распределения, пропуски, выбросы и корреляции.
2. Предобработка: удалили пустой столбец `furnished` и дубликаты, оставили объявления о продаже, убрали некорректные цены и площади, перевели цены в TRY, заполнили пропуски, закодировали категории через One-Hot и масштабировали `size` и `tom`. Цену логарифмировали через `np.log1p`.
3. Модели: LinearRegression, RandomForestRegressor и CatBoostRegressor, гиперпараметры подбирали через GridSearchCV. Выбрали CatBoost.
4. Приложение: API отдаёт прогноз, интерфейс отправляет в него данные из формы.

В тестовом ноутбуке дополнительно обучены две модели CatBoost, отдельно для продажи и для аренды. Категории в них передаются напрямую через `cat_features`. Приложение использует модель из первого ноутбука.

## Результаты

Сравнение моделей на тестовой выборке (ошибки в логарифмах цены):

| Модель | MAE | RMSE | MAPE, % | R² |
|---|---|---|---|---|
| LinearRegression | 0.35 | 0.47 | 2.77 | 0.52 |
| RandomForestRegressor | 0.32 | 0.43 | 2.52 | 0.60 |
| CatBoostRegressor | 0.32 | 0.43 | 2.52 | 0.61 |

Проверка на 20 новых объявлениях (10 продажа, 10 аренда), ошибки в лирах:

| Модель | MAE, TRY | RMSE, TRY | R² |
|---|---|---|---|
| Продажа | 217 185.89 | 400 406.98 | 0.68 |
| Аренда | 3 367.85 | 5 886.57 | 0.09 |

По аренде R² низкий: в 10 объявлениях обычные квартиры идут вперемешку с дорогими объектами, а у части дорогих не указана площадь.
